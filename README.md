# EduSysNet – Website Belajar Network & System

EduSysNet adalah starter project UAS Pemrograman Web I bertema edukasi yang membahas
dasar Network dan System Administration.

## Fitur yang sudah tersedia

- Heading dan paragraph
- Text formatting (`strong`, `em`, `mark`)
- Link / navigasi
- Image
- Table
- Ordered List
- Unordered List
- Form
- Elemen semantic HTML
- Audio
- Video
- Custom CSS
- 5 jenis selector CSS:
  - Tag
  - Class
  - ID
  - Attribute
  - Universal
- JavaScript:
  - Dark mode
  - Mobile navigation
  - Quiz interaktif
  - Validasi form
  - Tahun footer otomatis
- Responsive design

## Cara menjalankan

### Cara 1
Klik dua kali `index.html`.

### Cara 2 - Visual Studio Code
Gunakan extension Live Server, kemudian klik kanan pada `index.html` lalu pilih:

`Open with Live Server`

## Bagian yang WAJIB dipersonalisasi sebelum dikumpulkan

1. Ubah nama kelompok pada footer.
2. Ubah email `edusysnet@example.com`.
3. Sesuaikan isi materi menggunakan bahasa kelompok sendiri.
4. Jika memungkinkan, ganti audio dan video contoh dengan rekaman kelompok sendiri.
5. Tambahkan identitas anggota pada laporan UAS.
6. Upload source code ke repository GitHub.
7. Hosting website menggunakan GitHub Pages, Netlify, Cloudflare Pages, atau hosting lain.
8. Capture beberapa tampilan website untuk lembar jawaban.
9. Jangan mengumpulkan tanpa memahami kode. Pelajari bagian HTML, CSS, dan JavaScript
   agar dapat menjelaskan saat vlog/presentasi.

## Contoh bagian yang dapat dijelaskan saat presentasi

- HTML digunakan untuk struktur halaman.
- CSS digunakan untuk tampilan dan responsive layout.
- JavaScript digunakan untuk interaksi.
- Quiz menggunakan event `submit`.
- Dark mode menggunakan `classList.toggle()`.
- Pilihan tema disimpan menggunakan `localStorage`.
- Form menggunakan validasi JavaScript sebelum menampilkan pesan berhasil.

## Catatan

Form pada project ini merupakan form frontend dan tidak mengirim data ke database.
Pesan berhasil ditampilkan sebagai simulasi menggunakan JavaScript.
